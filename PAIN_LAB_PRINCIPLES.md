# AI Rules

## Who am I?

I'm not a Vue core contributor.

I'm a frontend engineer who writes Vue every day.

Everything in this repository should reflect that perspective.

---

## Project Goal

Help developers answer one question:

"Does the new Vue version actually solve my daily pain?"

---

## Build Principles

Keep it simple.

Prefer real-world scenarios.

Avoid unnecessary abstractions.

Don't build frameworks.

Don't optimize before a real problem exists.

Every page should feel like a small reproducible example from a real project.

---

## When writing code

Ask yourself:

"Would a normal Vue developer write code like this?"

If the answer is no,

simplify it.
