# docs

本目錄存放無法直接從程式碼看出的專案脈絡：為什麼做某個決定、以及怎麼操作專案。

- [`decisions/`](./decisions/README.md) — 記錄已經做出但沒寫進 code 的技術決策，例如「為什麼用雙 linter」。
- [`guides/`](./guides/README.md) — 操作型文件，例如「如何新增一個 pain scenario」。

專案理念與人設請見根目錄的 [`PAIN_LAB_PRINCIPLES.md`](../PAIN_LAB_PRINCIPLES.md)；scenario 的規劃/驗證流程請見 `.claude/skills/`。
