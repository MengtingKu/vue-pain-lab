# Create Pain Scenario

建立新的 Scenario 時，必須遵守 PAIN_LAB_PRINCIPLES.md。

---

# Process

## 1. Identify Pain

確認：

- 是否來自真實開發情境
- 是否能描述明確問題

---

## 2. Define Research Question

將痛點轉換成可驗證問題。

格式：

Question:

例如：

大量資料更新時，
Vue Runtime Cost 發生在哪裡？

---

## 3. Design Scenario

建立：

- 最小可重現案例
- 固定資料來源
- 固定更新流程

---

## 4. Keep Baseline

禁止：

- 提前最佳化
- 加入 workaround
- 改變原始問題

---

## 5. Define Evidence

說明：

- 觀察什麼
- 如何測量
- 預期比較方式

---

## Output

建立：

- Scenario folder
- README.md
- Vue component

README 必須包含：

- Question
- Hypothesis
- Scenario Design
- Benchmark
- Observation
- Next Step
